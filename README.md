# Compound War Room

Phone board for the Bærum → Stavanger family-house hunt.

- **War room:** https://alexpaskal9.github.io/stavanger-compound/
- **Stavanger 2027 cinematic digital twin:** https://alexpaskal9.github.io/stavanger-compound/stavanger-2027.html
- **Numbers-first strategy:** [`STRATEGY.md`](STRATEGY.md)

The digital twin is a single-file Three.js experience: fly the stylized night city, click every tracked house, filter by verdict, scrub the Apr–May 2027 budget timeline, and play the narrated top-three tour.

No login. Bookmark it, or Add to Home Screen.

Listings refresh from FINN every day at 18:00 CEST. Prices are asking prices, not sold prices. Syrinveien 27 is a sold benchmark, not a live bid.
